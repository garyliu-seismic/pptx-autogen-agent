# 原理图解

## 图解 Agent 循环
- 感知：把用户目标转化为可执行计划
- 行动：调用工具完成具体动作
- 观察：读取结果并修正下一步
- 循环直至任务完成，是 Agent 的核心工作方式
一句话结论：Agent 让大模型从「能聊」变成「能做事」。

## 图解 LLM 流水线
- 预训练：在海量语料上学习语言规律
- 指令微调：让模型学会听从并回答问题
- RLHF 对齐：让输出符合人类偏好与安全
- 推理应用：部署到对话、Agent、工具等场景
一句话结论：从「会语言」到「会干活」，靠的是三阶段训练与工程落地。

## 图解 Skill 构成
- 指令：明确目标与约束边界
- 示例：示范输入与输出
- 工具：可调用的函数与接口
- 触发条件：定义何时启用与停止
一句话结论：Skill 把「经验」打包成可复用的标准作业程序。
