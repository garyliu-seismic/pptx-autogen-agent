# Agent 原理：让模型自主行动

## 什么是 Agent
- 能感知环境并自主决策的智能体
- 不只是"问答"，而是"做事"
- 把大模型当作"大脑"
- 与环境持续交互直到任务完成

## 四大核心能力
- 感知：理解输入与反馈
- 规划：拆解任务、制定步骤
- 工具：调用函数、搜索、写代码
- 记忆：长期与短期记忆

## ReAct 工作循环
- 第1步：思考 Thought
- 第2步：行动 Action
- 第3步：观察 Observation
- 第4步：循环直到任务完成

## 典型应用
- 自动写代码与调试
- 数据分析与报告生成
- 多步骤任务自动化
- 与 Office 工具集成
