# LLM 科普：大语言模型

## 什么是大语言模型
- 基于海量文本预训练的深度学习模型
- 以 Transformer 架构为核心
- 通过预测下一个 Token 学习语言规律
- 具备理解、生成、推理能力

## 核心概念
- Token：模型处理文本的最小单元
- 上下文窗口：模型一次能"看到"的最大长度
- 参数规模：数百亿到数万亿参数
- 涌现能力：规模增大后出现的新能力

## 训练三阶段
- 第1阶段：海量语料预训练
- 第2阶段：监督微调对齐指令
- 第3阶段：人类反馈强化学习 RLHF

## 为什么重要
- 改变人机交互方式
- 成为新一代生产力工具
- 催生 Agent 与多模态应用
